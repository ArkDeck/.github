# Security policy

This is the default security policy for repositories in the ArkDeck organization
that do not carry their own `SECURITY.md`.

Please do not open public issues for security problems. Report them privately
through the "Report a vulnerability" button on the Security tab of the affected
repository (GitHub private vulnerability reporting). Include the affected
component, version or commit, and steps to reproduce.

These tools talk to real devices (flashing, install, debug), so reports about
unintended device writes, privilege boundaries, or path handling are especially
welcome.
