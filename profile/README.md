# ArkDeck

A debugging toolkit for OpenHarmony devices: flashing, debugging, tracing, and a viewer.

| Repository | What it is |
| --- | --- |
| [ArkDeck](https://github.com/ArkDeck/ArkDeck) | The main toolkit: macOS app, Windows client, CLI, and device agent daemon |
| [ArkForge](https://github.com/ArkDeck/ArkForge) | Rust flashing daemon for Rockchip devices (DAYU200 / RK3568) |
| [ArkTrace](https://github.com/ArkDeck/ArkTrace) | Trace capture and viewer tooling |
